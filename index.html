DustyBinaries

Old compilers. Real software.

We want to show that old technologies like Delphi 7, Pelles C and the Digital Mars compilers can still build useful, even beautiful, software. Native binaries, no heavy runtimes, a little dust on top.

Projects

Borion

A Tauri-style native application engine for Delphi 7: HTML/CSS/JS interfaces on WebView2, native logic in Delphi.

Delphi 7

WebView2

The TWebView2Browser control for Delphi 7, the foundation of Borion. It also works standalone.

Delphi 7

fbstats

Firebird size statistics: page census, BLOB measurement and duplication analysis behind a web UI.

Delphi 7 + Borion

fsql

A Firebird command-line shell modelled on the sqlite3 CLI. Replaces isql for day-to-day work.

Delphi 7 + Zeos

tdb

A gdb/pdb-style command-line debugger for Delphi 7 programs, hosting Borland's own debug kernel through COM.

Delphi 7

UReadLine

A minimal GNU-readline-like line editor for the Windows console, with history, completion and Emacs keys.

Delphi 7

Principles

  • Old toolchains, current results. Every project is built with a vintage compiler.
  • Native and lightweight. Small executables, quick startup.
  • Useful first, nostalgic second. The tools solve real problems today.
  • Modern where it counts. Web UIs, sqlite3-style CLIs and gdb-style debugging.
